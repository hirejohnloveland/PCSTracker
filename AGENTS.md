# AGENTS.md

Entry point for AI agents working in this repository.

Before adding or moving code, read [docs/project-structure.md](docs/project-structure.md).

C# methods, constructors and local functions use block bodies. Use `=>` only for read-only properties, lambdas and switch-expression arms. Put braces on every statement block. Name private instance fields `_camelCase` and private static fields `s_camelCase`. `.editorconfig` flags violations.
